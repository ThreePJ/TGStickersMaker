# TGStickers — Telegram Sticker Pack Merger & Editor

Десктопное приложение на **Python (PySide6)** для сбора, фильтрации, объединения и редактирования стикерпаков через Telegram Bot API.

## Возможности
- 📦 **Пакетная загрузка:** вставка ссылок на несколько стикерпаков и их быстрый просмотр с кэшированием.
- 🎨 **Выборка и объединение:** выбор нужных стикеров из разных паков и экспорт в новый стикерпак бота.
- ✏️ **Редактор собственных паков:** просмотр, переименование, удаление и сортировка стикеров в паках, принадлежащих вашему боту.
- 🍎 **Нативные эмодзи:** отображение и выбор эмодзи в стиле Apple Color Emoji.

---

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd TGStickers
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте файл окружения `.env`:
   - Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
   - Заполните ваши учетные данные Telegram Bot:
   ```env
   TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   TELEGRAM_USER_ID=123456789
   TELEGRAM_BOT_USERNAME=your_bot_username
   ```

4. Запустите приложение:
```bash
python main.py
```
